Both are OpenAI-compatible /v1/chat/completions servers: vLLM :8000, Ollama :11434, LM Studio :1234, OpenRouter, OpenAI — and Gemini at https://generativelanguage.googleapis.com/v1beta/openai with a key from aistudio.google.com. Either slot takes either kind. A slot with an empty Base URL or Model is skipped; the fallback runs only when the primary is unreachable, too slow, or returns a 5xx.
Ollama needs OLLAMA_ORIGINS=chrome-extension://* (macOS app: launchctl setenv OLLAMA_ORIGINS "chrome-extension://*", then restart it).
